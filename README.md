  - Categorized menu filters (*Espresso, Signature, Cold Brew, Pour Over, Patisserie*).

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Tooling**: Vite 8
- **Styling**: Tailwind CSS with custom obsidian & gold luxury design tokens
- **Icons**: Lucide React
- **Audio**: Web Audio API with procedural sound effects (pour, steam, notification chime)

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/mishalsabir/Aura-Coffee.git
cd Aura-Coffee
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```
